# `!sha256`

SHA-256 of a **string**, hex lowercase, UTF-8. Bind-only.

For a **tree**, use [`!sha256-json`](sha256-json.md).

## Syntax

```yaml
$Sum: !sha256
  $of: !ref $Values.password
```

Exactly `$of` (string). Mapping/seq is an error.

## Examples

### Annotation from a password string

```yaml
---
!bind
$PwHash: !sha256
  $of: !ref $Values.password
---
!emit
metadata:
  annotations:
    checksum/secret: !ref $PwHash
```

### Hash a formatted blob

```yaml
$Blob: !format
  - "%s:%s"
  - !ref $Values.user
  - !ref $Values.password
$Sum: !sha256
  $of: !ref $Blob
```

### Hash JSON (prefer the dedicated tag)

```yaml
$Sum: !sha256
  $of: !to-json-str $Values.config
```

Same as `!sha256-json $Values.config`.

## Common mistakes

<table>
<tr><th>Wrong</th><th>Right</th></tr>
<tr><td>

```yaml
---
!bind
$Sum: !sha256
  $of: !ref $Values.config
# $of must be a string; a mapping is an error
```

</td><td>

```yaml
---
!emit
metadata:
  annotations:
    checksum/config: !sha256-json $Values.config
# hash a mapping with !sha256-json
```

</td></tr>
<tr><td>

```yaml
---
!emit
metadata:
  annotations:
    checksum: !sha256
      $of: !ref $Values.password
# !sha256 is bind-only
```

</td><td>

```yaml
---
!bind
$Sum: !sha256
  $of: !ref $Values.password
---
!emit
metadata:
  annotations:
    checksum: !ref $Sum
# hash in bind, then !ref
```

</td></tr>
<tr><td>

```yaml
---
!bind
$Sum: !expr "sha256sum($Values.password)"
# no sha256sum() in !expr
```

</td><td>

```yaml
---
!bind
$Sum: !sha256
  $of: !ref $Values.password
# hash is the !sha256 tag
```

</td></tr>
</table>

## Comparison with Helm

`!sha256` hashes a **string** (UTF-8), hex lowercase — same bytes as `sha256sum` of that string.

<table>
<tr><th>Helm</th><td>

```gotemplate
hash: {{ .Values.password | sha256sum }}
```

</td></tr>
<tr><th>Knarr</th><td>

```yaml
---
!bind
$PwHash: !sha256
  $of: !ref $Values.password
```

</td></tr>
<tr><th>Difference</th><td>

Same behavior.

</td></tr>
</table>

<table>
<tr><th>Helm</th><td>

```gotemplate
hash: {{ printf "%s:%s" .Values.user .Values.password | sha256sum }}
```

</td></tr>
<tr><th>Knarr</th><td>

```yaml
---
!bind
$Blob: !format
  - "%s:%s"
  - !ref $Values.user
  - !ref $Values.password
$Sum: !sha256
  $of: !ref $Blob
```

</td></tr>
<tr><th>Difference</th><td>

Helm pipes `printf` into `sha256sum` in the template; knarr hashes in bind (`!format` then `!sha256`).

</td></tr>
</table>

<table>
<tr><th>Helm</th><td>

```gotemplate
checksum/config: {{ toJson .Values.config | sha256sum }}
```

</td></tr>
<tr><th>Knarr</th><td>

```yaml
---
!emit
metadata:
  annotations:
    checksum/config: !sha256-json $Values.config
```

</td></tr>
<tr><th>Difference</th><td>

`!sha256` hashes a string only. For a mapping use `!sha256-json` (same digest as `toJson | sha256sum`).

</td></tr>
</table>
