# `!sha256`

SHA-256 of a **string**, hex lowercase, UTF-8. A value, like [`!format`](format.md): bind or a field.

For a **tree**, use [`!sha256-json`](sha256-json.md).

## Syntax

```yaml
# $Values = {password: pw}
$Sum: !sha256
  $of: !ref $Values.password
# $Sum = 30c952fa…
```

- Exactly `$of` (string). Not `$over`. Mapping/seq is an error.
- `$Name?: !sha256` / `checksum?: !sha256` ↔ omit-capable `$of` (`?.`, no `?? ''`): missing string → omit the value.
- `$Name: !sha256` / `checksum: !sha256` ↔ `$of` always a value (`?? ''` or a required path): `""` → hash of the empty string.
- Pair error: `?:` + `?? ''` on `$of`, or a required key + omit-capable `$of` without `??`.
- Empty string value still hashes (hex stays) even on `?:`. Omit only if `$of` itself omits.
- `$of?:` is an error. Not a document. Not the whole `$then` of `!emit`. Not `$yield` of `!emit-foreach` (not a mapping).

## Examples

### Annotation from a password string

```yaml
# $Values = {password: pw}
!emit
checksum/secret: !sha256
  $of: !ref $Values.password
# checksum/secret: 30c952fa…
```

### Hash a formatted blob

```yaml
# $Values = {user: u, password: pw}
$Blob: !format
  - "%s:%s"
  - !ref $Values.user
  - !ref $Values.password
$Sum: !sha256
  $of: !ref $Blob
# $Sum = aa12c3c4…
```

### Hash JSON (prefer the dedicated tag)

```yaml
# $Values = {config: {a: 1}}
$Sum: !sha256
  $of: !to-json-str $Values.config
# $Sum = 015abd7f…
```

Same as `!sha256-json $Values.config`.

### Optional password checksum

```yaml
# $Values = {}
!bind
$PwHash?: !sha256
  $of: !ref $Values.password?
---
!emit
checksum/secret?: !ref $PwHash?
# no checksum/secret
```

Missing `password` → no `$PwHash` → no key. `password: ""` → hash of `""`. Always keep a hex:

```yaml
# $Values = {}
!bind
$PwHash: !sha256
  $of: !ref "$Values.password? ?? ''"
# $PwHash = e3b0c442…
```

## Omit

`$Name?: !sha256` ↔ omit-capable `$of` (no `?? ''`). Missing → omit bind. `password: ""` → hash of `""`.

```yaml
# $Values = {}
$PwHash?: !sha256
  $of: !ref $Values.password?
# no $PwHash
```

## Comparison with Helm

`!sha256` is a value. It hashes a **string** (UTF-8), hex lowercase — same bytes as `sha256sum` of that string. `?:` follows the same omit pair as [`!split`](split.md).

<table>
<tr><th>Helm</th><td>

```gotemplate
# $Values = {password: pw}
hash: {{ required "password" .Values.password | sha256sum }}
# hash: 30c952fa…
```

</td></tr>
<tr><th>Knarr</th><td>

```yaml
# $Values = {password: pw}
!validation
$rules:
  - !is-not-empty $Values.password?
$fail: "password"
---
!emit
hash: !sha256
  $of: !ref $Values.password
# hash: 30c952fa…
```

</td></tr>
<tr><th>Difference</th><td>

Same digest. `required` abort = `$fail`. Fail text differs.

</td></tr>
</table>

<table>
<tr><th>Helm</th><td>

```gotemplate
# $Values = {user: u, password: pw}
hash: {{ printf "%s:%s" .Values.user .Values.password | sha256sum }}
# hash: aa12c3c4…
```

</td></tr>
<tr><th>Knarr</th><td>

```yaml
# $Values = {user: u, password: pw}

  $of: !format

    - !ref $Values.user
    - !ref $Values.password
```

</td></tr>
