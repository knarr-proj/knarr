# `!sha256`

SHA-256 of a **string**, hex lowercase, UTF-8. Bind-only.

For a **tree**, use [`!sha256-json`](sha256-json.md).

## Syntax

```yaml
$Sum: !sha256
  $of: !ref $Values.password
```

- Exactly `$of` (string). Not `$over`. Mapping/seq is an error.
- `$Name?: !sha256` ↔ omit-capable `$of` (`?.`, no `?? ''`): missing string → omit bind.
- `$Name: !sha256` ↔ `$of` always a value (`?? ''` or a required path): `""` → hash of the empty string.
- Pair error: `$Name?:` + `?? ''` on `$of`, or `$Name:` + omit-capable `$of` without `??`.
- Empty string value still hashes (hex stays) even on `$Name?:`. Omit bind only if `$of` itself omits.
- `$of?:` is an error. Not in `!emit`.

## Examples

### Annotation from a password string

```yaml
!bind
$PwHash: !sha256
  $of: !ref $Values.password
---
!emit
checksum/secret: !ref $PwHash
```

### Hash a formatted blob

```yaml
$Blob: !format
  - "%s:%s"
  - !ref $Values.user
  - !ref $Values.password
$Sum: !sha256
  $of: !ref $Blob
```

### Hash JSON (prefer the dedicated tag)

```yaml
$Sum: !sha256
  $of: !to-json-str $Values.config
```

Same as `!sha256-json $Values.config`.

### Optional password checksum

```yaml
!bind
$PwHash?: !sha256
  $of: !ref $Values.password?
---
!emit
checksum/secret?: !ref $PwHash?
```

Missing `password` → no `$PwHash` → no key. `password: ""` → hash of `""`. Always keep a hex:

```yaml
!bind
$PwHash: !sha256
  $of: !ref "$Values.password? ?? ''"
```

## Omit

`$Name?: !sha256` ↔ omit-capable `$of` (no `?? ''`). Missing → omit bind. `password: ""` → hash of `""`.

```yaml
# $Values = {}
$PwHash?: !sha256
  $of: !ref $Values.password?
# no $PwHash
```

## Comparison with Helm

`!sha256` hashes a **string** (UTF-8), hex lowercase — same bytes as `sha256sum` of that string. `$Name?:` follows the same omit pair as [`!split`](split.md).

<table>
<tr><th>Helm</th><td>

```gotemplate
hash: {{ required "password" .Values.password | sha256sum }}
```

</td></tr>
<tr><th>Knarr</th><td>

```yaml
!bind
$PwHash: !sha256
  $of: !ref $Values.password
---
!validation
$rules:
  - !is-not-empty $Values.password?
$fail: "password"
---
!emit
hash: !ref $PwHash
```

</td></tr>
<tr><th>Difference</th><td>

Same digest. `required` abort = `$fail`. Fail text differs.

</td></tr>
</table>

  $of: !ref $Blob

</td></tr>
